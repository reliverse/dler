# Getting Started

Get up and running with Rempts in just a few minutes. This guide will walk you through creating your first CLI application.

## Prerequisites

<Callout type="info">
  Rempts requires Bun 1.0 or later. Install it from [bun.sh](https://bun.sh)
</Callout>

```bash
# Check your Bun version
bun --version
```

## Quick Start

<Steps>

### Create a new project

Use `rempts` to scaffold a new CLI project:

```bash
bunx @reliverse/rempts my-cli
cd my-cli
```

You'll be prompted for:
- **Project name**: Validated to contain only lowercase letters, numbers, and hyphens
- **Template**: Choose from `basic` (default), `advanced`, or `monorepo`
- **Package manager**: Select your preferred package manager (bun, npm, yarn, pnpm)

The tool will automatically:
- ✅ Create the project structure with file-based commands
- ✅ Initialize a git repository
- ✅ Install dependencies including `@reliverse/rempts-core`
- ✅ Set up TypeScript and testing with Bun
- ✅ Generate initial `dler.config.ts` configuration

### Explore the project structure

Your new CLI project includes:

```
my-cli/
├── cli.ts                # CLI entry point with async createCLI
├── commands/             # Command definitions (REQUIRED for file-based loading)
│   └── greet.ts          # Individual command files
├── dler.config.ts      # Configuration (auto-loaded)
├── .rempts/              # Generated files (auto-created)
│   └── commands.gen.ts   # Generated TypeScript types
├── package.json          # Dependencies including @reliverse/rempts-core
├── tsconfig.json         # TypeScript configuration
└── README.md
```

### Run your CLI

In development mode with hot reload:

```bash
rempts dev
```

Or run directly with Bun:

```bash
bun run cli.ts --help
```

### Add your first command

Create a new command in `commands/greet.ts`:

```typescript
import { defineCommand, option } from '@reliverse/rempts-core'
import { z } from 'zod'

export default defineCommand({
  name: 'greet',
  description: 'Greet someone',
  options: {
    name: option(
      z.string().min(1),
      { description: 'Name to greet', short: 'n' }
    ),
    excited: option(
      z.coerce.boolean().default(false),
      { description: 'Add excitement', short: 'e' }
    )
  },
  handler: async ({ flags, prompt, spinner, colors }) => {
    const spin = spinner('Preparing greeting...')
    spin.start()

    let name = flags.name
    if (!name) {
      name = await prompt('What is your name?')
    }

    spin.succeed()

    const greeting = colors.green(
      `Hello, ${name}${flags.excited ? '!' : '.'}`
    )
    console.log(greeting)
  }
})
```

### Test your command

```bash
# Run in development
rempts dev greet --name World --excited
# Output: Hello, World!

# Run tests
rempts test
```

### Build for production

Create optimized binaries for distribution:

```bash
# Build for current platform
rempts build

# Build for all platforms
rempts build --all
```

</Steps>

## Project Templates

rempts offers several templates to match your needs:

<Tabs groupId="template" defaultValue="basic">
  <Tab value="basic" label="Basic">
    Simple single-command CLI:
    ```bash
    bunx rempts my-cli --template basic
    ```
    
    **Perfect for:**
    - Learning Rempts
    - Simple scripts
    - Single-purpose tools
    
    **Includes:**
    - TypeScript setup
    - Example command with tests
    - Build configuration
  </Tab>
  
  <Tab value="advanced" label="Advanced">
    Multi-command CLI with all features:
    ```bash
    bunx rempts my-cli --template advanced
    ```
    
    **Includes:**
    - Multiple commands (init, validate, serve, config)
    - Configuration management
    - File validation system
    - Development server
    - Interactive license selection
    
    **Perfect for:**
    - Production CLIs
    - Developer tools
    - Complex applications
  </Tab>
  
  <Tab value="monorepo" label="Monorepo">
    Workspace setup for larger projects:
    ```bash
    bunx rempts my-cli --template monorepo
    ```
    
    **Features:**
    - Turborepo configuration
    - Multiple packages (cli, core, utils)
    - Changeset support
    - Parallel builds
    
    **Perfect for:**
    - Large teams
    - Multi-package CLIs
    - Scalable architectures
  </Tab>
</Tabs>

### External Templates

Use any GitHub repository as a template:

```bash
# GitHub repository
bunx rempts my-cli --template username/repo

# Specific branch
bunx rempts my-cli --template username/repo#branch

# NPM package
bunx rempts my-cli --template npm:template-package
```

## Manual Setup

If you prefer to set up manually:

<Steps>

### Install Rempts

```bash
bun add @reliverse/rempts-core @reliverse/rempts-utils
```

### Create your CLI entry point

```typescript
// cli.ts
import { createCLI } from '@reliverse/rempts-core'

const cli = await createCLI({
  name: 'my-cli',
  version: '1.0.0',
  description: 'My awesome CLI'
})

// CLI automatically loads commands from dler.config.ts
await cli.run()
```

### Add to package.json

```json
{
  "name": "my-cli",
  "bin": {
    "my-cli": "./cli.ts"
  },
  "scripts": {
    "dev": "rempts dev",
    "build": "rempts build",
    "test": "bun test"
  },
  "dependencies": {
    "@reliverse/rempts-core": "latest",
    "@reliverse/rempts-utils": "latest"
  }
}
```

### Create dler.config.ts

```typescript
import { defineConfig } from '@reliverse/rempts-core'

export default defineConfig({
  name: 'my-cli',
  version: '1.0.0',
  description: 'My awesome CLI',
  commands: {
    directory: './commands' // Enable file-based command loading
  }
})
```

<Callout type="info">
  The `commands.directory` setting enables **file-based commands**, where Rempts automatically discovers and loads commands from your `commands` directory. Each `.ts` file becomes a command, and nested directories create command hierarchies (e.g., `commands/db/migrate.ts` becomes `my-cli db migrate`).
</Callout>

### Create commands directory

```bash
mkdir commands
```

```typescript
// commands/hello.ts
import { defineCommand } from '@reliverse/rempts-core'

export default defineCommand({
  name: 'hello',
  description: 'Say hello',
  handler: async ({ colors }) => {
    console.log(colors.green('Hello from Rempts!'))
  }
})
```

</Steps>
