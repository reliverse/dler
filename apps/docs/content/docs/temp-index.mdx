# Rempts

Build production-ready, type-safe CLIs with strong type inference, validation, plugin system, and cross-platform distribution.

## What is Rempts?

Rempts is a complete ecosystem for building command-line interfaces with Bun. It combines a minimal, type-safe framework with powerful tooling for development, testing, building, and distribution.

## Why Rempts?

### Designed for Bun

Rempts is built specifically for the Bun runtime, taking advantage of:
- Native TypeScript execution
- Built-in test runner
- Fast startup times
- Bun Shell integration
- Single-file executables

### Type Inference First

Strong typing without manual annotations:

```typescript
import { defineCommand, option } from '@rempts/core'
import { z } from 'zod'

// Rempts infers everything
export default defineCommand({
  name: 'deploy',
  options: {
    env: option(
      z.enum(['dev', 'staging', 'prod']),
      { description: 'Target environment' }
    )
  },
  handler: async ({ flags }) => {
    // TypeScript knows flags.env is 'dev' | 'staging' | 'prod'
    switch (flags.env) {
      case 'dev':     // ✅ Autocompleted
      case 'staging': // ✅ Autocompleted
      case 'prod':    // ✅ Autocompleted
    }
  }
})
```

### Standard Schema Support

Use any validation library you prefer:

```typescript
import { z } from 'zod'
import * as v from 'valibot'

// Use your favorite schema library
options: {
  email: option(z.string().email()),
  port: option(v.number([v.minValue(1), v.maxValue(65535)]))
}
```

### Complete Ecosystem

Everything you need to build production CLIs:

- **rempts** - Project scaffolding
- **rempts dev** - Hot reload development with type generation
- **rempts build** - Multi-platform builds
- **rempts generate** - Generate TypeScript definitions from commands
- **rempts test** - Testing utilities
- **rempts release** - Automated distribution
